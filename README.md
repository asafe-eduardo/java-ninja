# Java Ninja

Repositório oficial do treinamento **Java Ninja**.  
Aqui você encontra a organização de pastas e materiais utilizados ao longo do curso: aulas, exercícios, projetos, desafios e conteúdos de apoio.
---

## Visão geral

Este repositório foi estruturado **fora das boas práticas de versionamento**, mas tem como objetivo permitir que você:

- acompanhe o conteúdo por módulos;
- execute exemplos e projetos localmente;
- pratique por meio de exercícios e desafios;
- revise materiais de apoio (checklists, guias, referências e afins).

## Pré-requisitos

Recomendado:

Módulo 2 - Aplicação Springboot

- **Java**: 17+
- **Maven**
- **Docker**
- IDE: IntelliJ IDEA / Eclipse / VS Code (com extensão Java)
- Git instalado

Módulo 3 - Aplicação React

- **Node**: 21.4.0
- **npm**: 10.2.4
- IDE: WebStorm / VS Code
- Git instalado

Módulo 4 - Fundamentos Java

- **Java**: 25+

**Recomendável**: usar SDKMAN.

Para checar se o Java está OK:

```bash
java -version
```

## Como usar este repositório

### 1) Clonar o repositório

```bash
git clone https://github.com/asafe-eduardo/java-ninja.git
cd java-ninja
```

## Conteúdo

O treinamento é organizado em pastas por módulo. Em cada módulo você geralmente encontrará o template:

- `x.y - NOME DA AULA/` (na pasta você terá todos os recursos utilizados nas aulas)

Sugestão de fluxo caso **não tenha noção de programação**:

1. Leia o `README.md` do módulo
2. Veja o Módulo 1 (história de Java e JavaScript)
3. Veja o Módulo 4 (fundamentos Java)
4. Inicie os Módulos 2 e 3 (Spring Boot e React)
